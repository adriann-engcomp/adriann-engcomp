## 🚀 Projeto em destaque: EpilepsyDB

Sistema web full-stack para acompanhamento clínico e cirúrgico de pacientes com epilepsia do HC-Unicamp, desenvolvido na Faculdade de Ciências Médicas (FCM).

- Migração de um banco legado em Access (.mdb) para **MySQL**, hoje com registros de 844 pacientes
- Módulos completos de cadastro, edição e acompanhamento de pacientes, candidatos à cirurgia, cirurgias e follow-ups
- Geração de relatórios em PDF e Excel
- Login, controle de permissões, logs de atividade, busca e ferramentas de backup
- Avaliação da viabilidade de modelos de machine learning (Regressão Logística, KNN, Random Forest, SVM) sobre os dados clínicos

**Stack:** PHP · MySQL · JavaScript · Bootstrap
